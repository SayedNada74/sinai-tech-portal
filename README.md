## 📌 عن المنصة (About The Project)

**SU IT Guide** هي منصة أكاديمية وتطويرية شاملة مصممة خصيصاً لتلبية احتياجات طلاب وأعضاء كادر تكنولوجيا المعلومات (IT) والحاسبات بجامعة سيناء. تهدف المنصة إلى تيسير متابعة المسار الدراسي، حساب وتوقع المعدل التراكمي (GPA) بدقة، تنظيم الجدول الأكاديمي، التواصل الفعال بين الطلاب والمشرفين، وتوفير خريطة طريق متكاملة للمهن والمجالات التقنية الأكثر طلباً في سوق العمل.

---

## ✨ المميزات الرئيسية (Key Features)

### 🧮 1. حاسبة ومحاكي المعدل التراكمي الذكي (Smart GPA Calculator & Simulator)
- حساب المعدل الفصل التراكمي والتراكمي العام (Semester & Cumulative GPA) بدقة وفقاً لنظام الساعات المعتمدة بجامعة سيناء.
- محاكاة وتوقع الدرجات المستقبلية والتخصصية للوصول لمعدل مستهدف (Target GPA Simulation).
- عرض تقديرات التخرج ومراتب الشرف الأكاديمية تلقائياً.

### 📱 2. تطبيق ويب متقدم (Progressive Web App - PWA)
- امكانية تثبيت المنصة كتطبيق مثبت ومستقل على أجهزة الجوال (iOS & Android) واللابتوب بكبسة زر واحدة.
- دعم الاستخدام دون اتصال بالإنترنت (Offline Mode Support) وتخزين البيانات الهامة سريعا.
- واجهة زجاجية حديثة متجاوبة بالكامل مع جميع مقاسات الشاشات (`100% Mobile Responsive`).

### 🛡️ 3. نظام حماية وأدوار متكامل (Role-Based Access Control - RBAC)
- تسجيل حسابات آمن للطلاب باستخدام البريد الأكاديمي الرسمي المعتمد (`@su.edu.eg`).
- لوحة تحكم كاملة للإدارة والإشراف (`Admin & Super-Admin Portal`) لإدارة المقررات، الإعلانات، المستخدمين، والموارد الأكاديمية.
- إمكانية معايرة وقيود الأمان التلقائية لمنع أي دخول غير مصرح به لصفحات الإشراف.

### 🔔 4. إشعارات أنميشن زجاجية حديثة (Glassmorphic Toast Notifications)
- إشعارات تفاعلية عائمة تظهر فور اتخاذ أي قرار أو إجراء في المنصة (إضافة، تعديل، حفظ، حذف، إلخ) بألوان وأنيميشن سلاسل.

### 🌐 5. دعم كامل للغتين العربية والإنجليزية (Bilingual RTL / LTR Support)
- تبديل فوري ومباشر بين اللغة العربية والإنجليزية مع تعديل اتجاه الواجهة بالكامل تلقائياً بدون إعادة تحميل الصفحة.

### 🌙 6. وضع ليل وفاتح فاخر (Sleek Dark & Light Modes)
- تصميم فاخر متناسق مع شعار الجامعة الرسمي عالي الوضوح والتباين في كل الأوضاع.

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Framework**: [Next.js 16 (App Router & Turbopack)](https://nextjs.org/)
- **UI Library**: [React 19](https://react.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/) & Vanilla CSS Tokens
- **Icons & Animations**: [Lucide React Icons](https://lucide.dev/) & [Framer Motion](https://www.framer.com/motion/)
- **Database & Backend**: [Supabase Integration Ready](https://supabase.com/)
- **Analytics**: [Vercel Web Analytics](https://vercel.com/analytics)
- **Deployment**: [Vercel Platform](https://vercel.com/)

## 🚀 التشغيل المحلي (Quick Start)

لترتيب وتغشيل المنصة محلياً على جهازك، اتبع الخطوات التالية:

### 1. استنساخ المستودع (Clone Repository)
```bash
git clone https://github.com/SayedNada74/sinai-tech-portal.git
cd sinai-tech-portal
```

### 2. تثبيت الحزم والمكتبات (Install Dependencies)
```bash
npm install
```

### 3. تشغيل سيرفر التطوير (Run Development Server)
```bash
npm run dev
```

افتح متصفحك وادخل على: [http://localhost:3000](http://localhost:3000)

## 📁 هيكل المشروع (Project Structure)

```text

├── app/                  # Next.js App Router (Pages, Layouts & API Routes)

│   ├── navbar.tsx        # Responsive Navigation Bar
│   └── pwa-installer.tsx # PWA Installation Banner & Service Worker Handler
├── context/              # React Context State Providers (Auth, App, Social)
├── public/               # Static Assets, Icons, Manifest & Service Worker
└── README.md             # Project Documentation
```
